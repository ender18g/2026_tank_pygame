# LCDR Allan Elsberry's Tank Game
this is an example github repo for ew200

### Description
In tank game your goal is to kill all enemy tanks and survive

### This is a screenshot from the actual game:
![screen shot of game](tank_screen.png)

### How to Play:
1. Clone this repository
2. Install `pygame-ce` with `pip install pygame-ce`
3. run game.py, `python3 game.py`
---
1. use the arrow keys to move the tank around
2. shoot enemies by hitting the spacebar key
3. avoid hitting crates! They will explode cause you to lose life
4. Avoid enemy tanks - they will drive toward you and attempt to hit your tank.

---
## Tank game features
1. Multiplayer option for additional tank (+4)
2. Muzak - plays music in background (+2)
3. Fancy Fonts - uses custom fonts for score (+1)
